# مكتبة مهارات حنين 🎬✨

مكتبة واحدة تجمع كل المهارات التي يحتاجها Claude لإنتاج:
فيديوهات الإنجاز الشهري، وإعلانات المبادرات، وتوثيق الفعاليات، والعروض التقديمية، والتصاميم والحركة.

## كيف تعمل؟

```
طلب في محادثة Claude
        ↓
مهارة «البوابة» المحفوظة في حساب Claude  (gateway/SKILL.md)
        ↓
تسحب هذه المكتبة من GitHub
        ↓
تقرأ القواعد العامة  →  تختار المهارة المناسبة  →  تجلب المهارات الخارجية عند الحاجة
```

## محتوى المكتبة

| المجلد | المحتوى |
|---|---|
| `gateway/` | مهارة البوابة — تُحفظ مرة واحدة في Claude |
| `skills/_house-rules/` | القواعد العامة لكل عمل (العربية، المقاسات، الاعتماد قبل التنفيذ) |
| `skills/monthly-achievement-video/` | فيديو الإنجاز الشهري — هوية ثابتة وحركة متجددة |
| `skills/initiative-ad/` | إعلان مبادرة |
| `skills/event-documentation/` | فيديو توثيق فعالية |
| `skills/lesson-deck/` | العروض التقديمية للدروس التطبيقية بطريقتي الثابتة |
| `external/` | المهارات الخارجية الرسمية (تُجلب من مصدرها عند الحاجة، لا تُنسخ) |
| `CATALOG.md` | فهرس كل المهارات ومتى تُستخدم |

## التحديث

- عدّلي أي ملف هنا على GitHub ← يصل التعديل لكل المحادثات القادمة تلقائيًا.
- المهارات الخارجية تُجلب بأحدث نسخة رسمية في كل مرة عبر `external/sync.sh`.
